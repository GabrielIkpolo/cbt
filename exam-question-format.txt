The Exam Questions must have the following columns:
subject
durationMinutes
text
options
correctAnswer
image
examId

# The subject column should contain the Subject of the exam

# The durationMinutes should contain the duration of the exam in minutes eg: 10 for 10 minutes

# The text should contain the question asked in the exam.

# The options is for options A to D and must be in this format:

A: the option A; B: the option B; C: the option C; D: the option D

# Note each option ends with a semi-colon apart from the last option which is option D. And it must all be in one column, the "options column"
 for question 1, and so it will be for each question in question 2 and 3 and so on.

# The correctAnswer should contain only the correct option, either A, B, C or D

# The image column is optional, if you must add an image, let the image name be unique eg: subject-q1-description.png. Add this in 
its correcponding question number row. Later on, you can then upload the images individually in the admin or lecturer interface

# examId: the value for the examId. It can be anything eg: exam123, it will not be used anyway, and a unique exam Id will be autogenerated


# All these should be arrange in a .csv file and uploaded through the admin or lecturer interface.
